# 짧게 일하고 알차게 벌려면?

단기 당근알바 공고 866건을 살펴보는 한국어 발표용 HTML 슬라이드 덱입니다. 검색 키워드를 일거리 유형별로 소개하고, 시급형과 건별형을 분리해 2026년 최저시급, 4시간 이하 공고, 급구와 웨이팅 대행 사례를 비교합니다.

## 발표자료 보기

[GitHub Pages로 발표 보기](https://jihyeson69-dev.github.io/daangn-alba-efficiency/). `index.html`은 12장으로 구성되어 있습니다.

## 조작 방법

- `←` / `→`, `Space`, `PageUp` / `PageDown`: 이전·다음 슬라이드
- `Home` / `End`: 첫 장 / 마지막 장
- `F`: 전체 화면 전환
- 아래쪽 화살표·점: 원하는 슬라이드로 이동
- 휴대전화: 좌우로 밀기

## 분석 범위와 기준

- 분석 파일: 작업 폴더의 당근알바 검색 공고 데이터 (원본 CSV는 공개 저장소에 포함하지 않음)
- 분석 표본 866건, 17개 검색어, 서울·부산, 게시일 2026년 5월 7일–10월 2일
- 급여 형태는 시급 477건, 건별 332건, 일급 57건으로 구분
- 시간당 비교는 직접 시급과 시간을 확인해 환산 가능한 일급 52건, 총 529건
- 명시 근무시간을 계산할 수 있는 공고 376건 중 4시간 이하 171건
- 건별 보수는 작업시간을 알 수 없어 시급으로 환산하지 않음
- 표본 제목에서 급구·오늘·당일·지금 표현이 있는 59건을 긴급성 그룹으로 분류
- 2026년 법정 최저임금은 고용노동부의 시급 10,320원 발표 자료 기준

검색어별 공고는 서로 겹칠 수 있고, 키워드가 실제 업무와 일치하지 않을 수 있습니다. 공고 금액은 실제 체결·지급액과 다를 수 있습니다. 이동·준비시간과 업무 난이도는 CSV에 없어 결과를 기술통계로 해석합니다.
